# Managed Device Access Guide

## Standard device support

Employees can request support for a company-managed device through the IT service process. Include the device asset label when available, but do not include passwords, tokens, or screenshots containing sensitive information.

## Approval boundary

Only IT specialists can review access exceptions. The policy-support system can create a mock review request but never changes device configuration or permissions.
